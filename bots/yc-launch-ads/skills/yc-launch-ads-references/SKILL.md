# YC Launch Ads: references

Templates, the worked example and reference tables for the YC Launch Ads steps. Everything here is invented and labelled as an example, or is a method, not a result. Copy the shape, never the facts. Never present an example number as the owner's. Checks named here are in yc-launch-ads-checks: each has a script in this bot's `scripts/` folder, with the written checklist as the fallback when code cannot run.

## Where each part lives (repo edition)
The material is split into files in this bot's `references/` folder so each one stays short. When another skill points here by section name (for example "Templates" or "Worked example"), open the file listed for that section. Inside a Grok Bot template, where only the skills are installed, the template edition of this skill keeps the sections inline.
- **Worked example**: `references/worked-example.md`
- **Templates**: `references/templates.md`
- **Claims lanes and policy**: `references/claims-lanes-and-policy.md`
- **Hook and script library**: `references/hook-and-script-library.md`
