# YC X Launch Desk: Fill-in templates: YC X Launch Desk

Fill every field, then run the check named under it. [NEED] fails every check on purpose.

### 1. One-page brief
Check: The fields check (brief)
```
Product:
Buyer:

Proof:
Offer:
Destination:
KPI:

Counted from:
T0:
Time zone:
Launch owner:
Replies owner:
Backup:
Quiet window hours:
Network path: LINEUP | NO-NETWORK
Ranking claims re-checked on: {DATE}, against current public X documentation
```


### 5. Video script card
```
[0-5s]   HOOK | on screen: ... | spoken: ... | text: ... | camera: ... | doubt: 1
[5-15s]  PROBLEM | ...
[15-30s] AGITATE | ...
[proof]  AHA 1 | ...
[...]    AHA 2 | ...
[dest]   OUTCOME | ...
[close]  PRODUCT IN THE CLOSE | ...
Four elements: claim / early payoff / no context gaps / strongest outcome
Mute test: | Eyes-closed test:
```
Doubts: 1 is this what I clicked; 2 is this for me; 3 is it worth staying.

### 6. Lineup log
Check: The lineup-log check
```
| Account | Fit | Reach | Relationship | Last ten checked | Check result | Decision | Draft | Status |
|---|---|---|---|---|---|---|---|---|
| [Account 1] | 0-3 | 0-3 | cold/seen/replied/friend | {DATE} | pass/fail | core/bench/skip/watch | <distinct draft> | drafted |
```
Status values: drafted, approved by owner, creator wrote own, sent by owner, replied, skipped.

### 7. No-network plan
```
Ten real notes: 1. <who asked about the problem, described> -> <draft>
Reply plan (5 live conversations, no product links): ...
Communities (max 3, rule checked by owner): ...
Stranger-first changes to the post: ...
```

### 9. Gates file (T-12h)
Check: The gates check (`scripts/check_gates.py`)
```
G1: PASS | destination loads on a phone, offer matches | evidence: ...
G2: PASS | KPI counter logged a test sign-up | evidence: ...
G3: PASS | post frozen after harsh read | evidence: freeze record
G4: PASS | people plan logged | evidence: lineup check PASS or no-network plan
G5: PASS | every draft approved by owner | evidence: ...
G6: PASS | quiet window agreed | evidence: ...
G7: PASS | replies owner and backup named | evidence: ...
G8: PASS | rollback plan written | evidence: ...
Verdict: GO
```
RISK lines need "accepted: yes". FAIL lines need "owner:" and "deadline:".
