# X source scan

## When
You need source material with proof people cared, for a founder X account. Not a content calendar. Not a draft queue.

## Floor
Start at `min_faves:500` on the last 7 days. If the page is noise, raise to 1000, then 2000, then 5000. Say which floor you settled on. Also run the same topic with `min_faves:1000 filter:media`.

The number is niche-relative. 500 likes in a broad topic is noise. 500 likes in a tight vertical can be that account's best post of the year.

## Search
- Search X itself, not the web about X. If you are reading articles, stop.
- Keyword search: the words people actually used.
- Idea search: the concept even when they never use your terms. Example: "a founder posting a screenshot of a customer message that made them look good" is a concept, not a keyword.
- Open the full reply thread when the value is in the responses.
- Restrict window (last 7 days or since a date), media, include or exclude accounts as asked.
- Do not invent metrics. Only numbers shown on the post.

## Return
5 to 8 candidates, ranked by how repackageable they are, NOT by how big they got. For each:
1. Link
2. What it is: post, screenshot, demo video, launch, story, or thread
3. Engagement as reported on the post
4. Core value in one sentence. Name the job: status, surprise, fear, usefulness, identity, contrast, or a question they had to answer
5. Why it stopped people (first line, first frame, or image)
6. Where execution was weak, and what would make ours a 7
7. Standing: can this founder post about it from lived material? If not, drop it

Flag any claim that needs checking. Outside engagement numbers describe the source post only; never present them as the owner's.

## Do not
- Draft posts
- Rewrite with synonyms
- Follow, like, reply, or publish
- Rank by views
- Return three posts from the same account unless they are doing different jobs
- Force a product mention
